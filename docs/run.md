# Як запустити тренажер

## Спосіб 1: ярлик (найпростіше)

1. Повністю закрийте Dota 2, якщо вона відкрита.
2. Двічі клацніть **`start_training.bat`** у папці проєкту.
3. Запуститься Dota у режимі Workshop Tools і одразу завантажить тренажер.

Якщо відкрилися лише вікна інструментів (Asset Browser), а гра не почалася, скористайтеся способом 2.

## Спосіб 2: через Workshop Tools вручну

1. Steam → ПКМ на **Dota 2** → **Запустити Dota 2 Workshop Tools**.
2. Виберіть **carry_lane_academy** → **Launch Custom Game Tools**.
3. В Asset Browser відкрийте **VConsole** (іконка з `>_` угорі).
4. У поле вводу внизу VConsole вставте і натисніть Enter:
   ```
   dota_launch_custom_game carry_lane_academy dota
   ```

## Що буде далі

1. **Меню:** виберіть сторону, лінію, складність, тривалість → **Почати**.
2. **Вибір героя:** звичайний екран Dota, можна взяти будь-якого.
3. **Прегейм:** купуйте предмети, йдіть на лінію. Боти з'являться автоматично.
4. **Горн (0:00):** стартує таймер тренування праворуч угорі.
5. **Кінець таймера:** гра стає на паузу, з'являються результати. **Ще раз** запускає все спочатку.

## Корисні команди консолі

| Команда | Що робить |
|---|---|
| `cla_status` | Показати стан і скільки часу лишилось |
| `cla_finish` | Завершити тренування зараз |
| `cla_test` | Запустити тести підрахунку |

## Якщо щось не працює

У VConsole введіть у фільтр `CLA` і надішліть Claude всі рядки `[CLA]` разом з червоними помилками (`error`, `Script Runtime Error`).
