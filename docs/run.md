# Як запустити аддон (для перевірки)

> Покрокова інструкція зі створення карти й першого запуску: [hammer_01_first_map.md](hammer_01_first_map.md).
> Цей файл — коротка шпаргалка.

## Запуск

Карта аддона: `carry_lane_academy`. Запасний варіант для перевірки коду без нашої карти: стандартна карта `dota` (замість `carry_lane_academy` в останньому слові команди).

1. Steam → ПКМ на Dota 2 → **Запустити Dota 2 Workshop Tools**.
2. У вікні вибору аддона оберіть **carry_lane_academy** → **Launch Custom Game Tools**.
3. Відкрийте консоль: в Asset Browser меню **Tools → VConsole** (або клавіша `~` у грі).
4. У полі вводу консолі напишіть і натисніть Enter:
   ```
   dota_launch_custom_game carry_lane_academy carry_lane_academy
   ```
5. Коли гра завантажиться, у консолі мають з'явитися рядки з `[CLA]`, зокрема:
   ```
   [CLA][INFO] bootstrap ok (ruleset=2026-10-dev-0, trust=T0)
   ```
   На карті `dota` додатково буде `[CLA][ERROR] На карті немає сутності 'cla_radiant_safe_hero_spawn'`:
   там нашої точки спавну немає, це очікувано.

## Що перевірити

| # | Перевірка | Очікувано |
|---|---|---|
| 1 | Герой | Автоматично Anti-Mage за Radiant, рівень 1 |
| 2 | Золото на старті | Запишіть число: це штатне стартове золото кастомки (порівняємо зі звичайним матчем) |
| 3 | HUD праворуч угорі | Таймер `10:00`, рядок `LH 0 / DN 0 ...`, жовтий напис «Локально · не враховується в рейтинг» |
| 4 | Після горну (0:00) | Таймер іде вниз від 10:00 |
| 5 | Пауза (F9) | Таймер зупиняється |
| 6 | Добивання крипа | LH збільшується |
| 7 | Консоль: `cla_test` | Усі рядки `PASS`, у кінці «0 провалено» |
| 8 | Консоль: `cla_status` | Показує стан `PLAYING` і час |
| 9 | Консоль: `cla_finish` | У консолі `Сесія: PLAYING → FINISHED (debug_command)` |

## Якщо щось пішло не так

Скопіюйте з консолі всі рядки з `[CLA]` та будь-які червоні помилки (`Script Runtime Error`, `error`) і надішліть Claude.
