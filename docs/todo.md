## Зміна курсу (19.10.2026)

Власник вирішив: **без Hammer, на стандартній карті Dota, лише для особистих тренувань.**
Тому з ТЗ беремо суть (обрати сторону, лінію, героя, складність, тривалість → тренуватися → результати),
а публічну частину (Workshop, онлайн-рейтинг, турніри, бекенд) **відкладено без терміну**.

| Питання | Рішення |
|---|---|
| Карта | Стандартна `dota`. Інші лінії вимикаються (`dota_disable_*_lane`) |
| Боти | Вбудовані боти Dota через `Tutorial:AddBot`; 5 рівнів = passive / easy / medium / hard / unfair |
| Герой гравця | Будь-який, через стандартний екран вибору героя Dota |
| Запуск | `start_training.bat` або консоль Workshop Tools |
| Мова | Українська (+ англійська локалізація) |
| Власна карта `content/maps/carry_lane_academy.vmap` | Не використовується; залишена в репозиторії, можна видалити |

## Відомі обмеження

- Боти Dota грають лише частиною героїв (список у `configs/bots.lua`).
- Поведінку ботів ми не контролюємо: вони можуть піти з лінії, ротуватися тощо.
- Результати локальні (trust tier T0), ніде не зберігаються після перезапуску.

## Етап A — Тренажер на стандартній карті

- [~] **A1 Меню перед грою:** сторона, лінія, складність, тривалість → «Почати».
- [~] **A2 Стандартний вибір героя Dota** після меню.
- [~] **A3 Лінія:** крипи йдуть лише на обраній лінії.
- [~] **A4 Боти:** союзний сапорт + 1–2 суперники на лінії залежно від ролі.
- [~] **A5 Таймер** за ігровим часом, стартує з горном, пауза не витрачає час.
- [~] **A6 HUD:** таймер, налаштування, LH/DN/GPM/XPM.
- [~] **A7 Результати:** пауза гри, LH, DN, GPM, XPM, рівень, смерті, кнопка «Ще раз».
- [~] **A8 Ярлик запуску** `start_training.bat`.

**Приймання етапу A:** запуск → меню → вибір героя → боти на лінії → 5 хв тренування → екран результатів → «Ще раз» відкриває меню знову.

## Етап B — Покращення (після перевірки A)
